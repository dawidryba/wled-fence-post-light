# Notatki projektowe (po polsku)

Robocze dokumenty z projektowania elektroniki. Dla budowy lampki wystarczą przewodniki po angielsku: [montaż](../assembly.md) i [uruchomienie](../bringup.md).

| Plik | Zawartość |
|---|---|
| [`schemat.md`](schemat.md) | Sieci, lista części z numerami LCSC, warianty montażu |
| [`testy.md`](testy.md) | Wyniki testów i symulacji, założenia i ograniczenia |
| [`wymiary-elektroniki.md`](wymiary-elektroniki.md) | Wymiary złożenia elektroniki w układzie lampki |

Dokumenty odzwierciedlają stan z etapu projektowania, więc część punktów kontrolnych może być już zamknięta.
